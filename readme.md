### 🛡️ AEGIS DevOps AI
**An Autonomous AI Agent for CI/CD Failure Detection, Root-Cause Analysis, and Automated Remediation**

My main DevOps-focused project explores how AI can assist when a software build or pipeline fails.

**Workflow I'm developing:**

1. Trigger a CI/CD pipeline through GitHub and Jenkins.
2. Build and test a Java application using Maven and JUnit.
3. Collect and organize relevant failure logs and repository context.
4. Use an LLM through the Groq API to analyze errors and propose remediation.
5. Validate suggested fixes and progressively develop safer automated recovery workflows.

**Technology stack:** Python · FastAPI · Groq API · Jenkins · GitHub · Java · Maven · JUnit · Docker · OWASP Dependency-Check

*Current direction: improving remediation reliability, introducing approval-gated changes, strengthening validation, and exploring Kubernetes and additional DevSecOps tooling.*

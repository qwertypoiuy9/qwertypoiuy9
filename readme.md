### 01 · AEGIS DevOps AI
**AI-assisted CI/CD failure detection, root-cause analysis, and remediation**

AEGIS explores how an AI agent can help developers understand pipeline failures by assembling useful logs and repository context, asking an LLM to analyze the failure, and proposing a remediation path.

**Workflow under development**
1. Run a Java/Maven build and automated tests in a Jenkins pipeline.
2. Gather relevant failure output and repository context.
3. Use an LLM through the Groq API to analyze errors and suggest a fix.
4. Validate proposed changes before progressing toward safer, approval-gated remediation.

`Python` `Jenkins` `Groq API` `GitHub` `Java` `Maven` `JUnit` `Docker`

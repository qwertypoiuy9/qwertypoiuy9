## 🚀 Featured Projects

### 🛡️ AEGIS: Autonomous AI-Powered DevOps Remediation Agent
An intelligent agent that analyzes failed CI/CD builds, studies pipeline logs, identifies likely root causes and suggests context-aware fixes.
- Jenkins + GitHub webhook-triggered pipelines, Docker-based delivery
- LLM-powered root-cause investigation, automated testing and vulnerability scanning
- **Stack:** `Python` `FastAPI` `Groq API` `Jenkins` `Docker` `Maven` `Java` `AWS EC2` `Linux`

### 🌾 KisanQ: Smart Farmer Procurement Platform
An AgriTech platform that helps farmers manage procurement slots, queues and payments.
- Slot booking, token/queue management, status and payment tracking
- Regional-language voice assistance with IVR/DTMF interaction
- **Stack:** `React` `JavaScript` `Supabase` `PostgreSQL` `Gemini API`

### 🛢️ Baghewala Digital Twin: AI-Powered Well Optimization
A digital twin prototype for heavy-oil well optimization and well-to-surface operational analysis.
- Interactive 3D well and artificial-lift visualization, CSS and SRP parameter analysis
- Monitoring dashboards, what-if simulation and AI-assisted recommendations
- **Stack:** `React` `TypeScript` `Three.js` `Python` `FastAPI`
- *Uses simulated/demo data; real industrial integration is a future direction.*

### 📄 LetMeCheck: AI Resume Analyzer & Career Accelerator
Helps students and early-career professionals improve their resumes and prepare for jobs.
- ATS compatibility check, role-based evaluation, skill-gap identification
- Learning recommendations and a career dashboard
- **Stack:** `React` `Vite` `JavaScript` `Supabase` `Firebase`
